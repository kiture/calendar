# Backend of AI Group Calendar

## Description

The backend of the AI Group Calendar is developed using Express.js and PostgreSQL. It handles the server-side logic, database interactions, and AI integration for event suggestions.

## Tech Stack

- **Express.js**: A web application framework for Node.js.
- **PostgreSQL**: A powerful, open-source object-relational database system.

## Getting Started

To set up the backend locally, follow these steps:

1. **Install dependencies**:

   ```bash
   npm install
   ```

2. **Run database migrations**:
   ```bash
   npm run migration
   ```
   This will set up your database schema and initial data.

3. **Run the backend server**:
   ```bash
   npm start
   ```

This will start the backend server using tsx watch mode, allowing it to handle API requests and interact with the database.
